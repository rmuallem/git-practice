
# IT Support Portal

A small web application created as a practical learning project using HTML and JavaScript.

## Project Overview

The IT Support Portal allows users to create and manage simple IT support tickets.

## Features

- Create IT support tickets
- Select ticket priority: Low, Medium, or High
- Automatically assign ticket numbers
- Display tickets on the page
- Mark tickets as Resolved
- Delete tickets
- Save tickets using browser localStorage
- Keep tickets after refreshing the page

## Technologies

- HTML
- JavaScript
- Browser localStorage
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter an IT problem and select a priority.
4. Click "Create Ticket".
5. Manage tickets using the Resolve and Delete buttons.

No installation or backend server is required.

## What I Learned

- Creating a web interface with HTML
- Using JavaScript functions and events
- Working with DOM elements
- Managing data with arrays and objects
- Saving and loading data using localStorage
- Using Git branches, commits, and pull requests

## Project Limitations

This is a learning project, not a production ticket system.

Tickets are stored locally in the browser. There is no central database, authentication, or backend.
